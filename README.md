# Guild2 Editor

冒険者ギルド物語2のセーブデータをブラウザ内だけで解析・編集・ZIP出力するための静的サイト版です。

## GitHub Pages

このリポジトリをGitHub Pagesで公開できます。サーバー処理は使用せず、セーブデータはブラウザ内で処理します。

推奨公開先:

`https://n4okins.github.io/guild2editor/`

## 現在の実装

- ZIP読込（JSZip）
- `tmp2` binary plist読込
- NSKeyedArchiverのUID参照を保持したモデル化
- ネストした `NS.data` の検出
- 構造概要表示
- 一部フィールドの編集
- 編集後binary plist再生成
- `tmp3` 前半の再計算
- 元ZIPの他ファイル保持
- ZIP書出し
- ブラウザ内基本整合性検査

## tmp3

解析資料に基づき、v5.10系のZIP import64に合わせて前半を生成します。

`first = MD5("222" + MD5(tmp2).hexdigest + "333")`

64桁の後半は元ZIPから保持します。ZIPインポート時は前半32桁が内容検証に使われ、後半は移行先で再生成されるためです。

## 重要

これは研究・編集用ツールです。ゲーム本体へのインポート成功、全フィールドの意味的整合性、将来版との互換性は保証しません。必ず元セーブをバックアップしてください。

ゲームのIPAや実セーブ、個人識別値はリポジトリへ含めません。
