# v0.4 UI

The v0.4 editor uses constrained controls for values whose ranges are confirmed and read-only presentation for fields whose update rules are not confirmed.

Item creation uses staged selection: category, group, base item, normal title, ultra title, quantity. Category 1 follows the current Wiki group/order and includes unresolved post-v5.10 names in place. Unresolved names can be inspected but cannot be written until their internal ID is confirmed.
